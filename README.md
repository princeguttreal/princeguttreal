# PRINCE' GUTT — Áudio ao Vivo

Site-portfólio profissional de Prince' Gutt, com foco em operação de áudio ao vivo, suporte técnico, PA/FOH, monitores, montagem de palco e trabalhos em eventos.

## Estrutura

- `index.html` — página principal, serviços, equipamentos, portfólio e contatos.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — navegação mobile e ano automático do rodapé.
- `assets/portfolio/` — fotografias dos eventos do portfólio.

## Visualização pelo GitHub

O código-fonte pode ser consultado diretamente neste repositório. Para servir a página como um site estático usando apenas o GitHub, habilite **Settings → Pages → Deploy from a branch → main → /(root)**. Depois da ativação, o GitHub informará o endereço público do site em Settings → Pages.

## Manutenção

Edite os textos em `index.html` e os estilos em `styles.css`. Mantenha as imagens otimizadas para web e os nomes de arquivo consistentes com os caminhos definidos na galeria.
